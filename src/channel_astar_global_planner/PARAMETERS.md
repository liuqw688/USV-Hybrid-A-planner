# 参数作用及调节说明

本说明对应当前源码与配置，不承诺每个参数可在线更新。多数参数仅在构造时读取：编辑YAML后请停止旧实例并重新启动。launch内追加参数可能覆盖YAML；可用 `ros2 param dump /节点名` 核对运行值。

数值“增大/减小”指其他条件不变时的趋势，不是无限调大都有效。布尔值按开/关解释；话题和frame必须与生产者一致。不要同时降低安全半径、冗余及急停距离来追求直线效率。


## config/channel_astar.yaml

当前配置值不是节点内置默认值，其他launch也可能覆盖它。

| 参数 | 当前YAML值 | 作用、关联及调大/调小影响 |
|---|---|---|
| `lane_costmap_topic` | `/channel/lane_costmap` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `odom_topic` | `/odom` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `goal_topic` | `/goal_pose` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `output_topic` | `/astar_channel_waypoints` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `active_goal_topic` | `/goal_pose_from_astar` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `waypoint_spacing` | `100.0` | 沿A*累计弧长的普通采样间距(m)。增大：航点更少、Hybrid单段更长；减小：目标切换更频繁、端段连接更细；须大于goal_switch_distance。 |
| `goal_switch_distance` | `8.0` | 普通航点切换半径(m)。增大：更早切换、可能削切转弯；减小：更接近航点才切换、可能频繁减速；必须小于航点间距。 |
| `mandatory_goal_distance` | `1.5` | 必经途经点到达半径(m)。增大：经过误差更大、切换更早；减小：要求更精确、跟踪困难时可能不切换。 |
| `right_channel_only` | `true` | true：主体限制主航道，仅起末段开放左/外连接；false：放开0..95语义搜索，右行限制明显弱化，并不取消物理安全检查。 |
| `main_lane_value_max` | `20` | 主航道语义上界，须与管理器一致。增大/减小会改变类别解释而非物理安全距离；不要单包随意调整。 |
| `opposite_lane_value` | `75` | 对向航道语义编码，须与管理器opposite_value一致。大小不是概率或距离；不一致会漏判左航道。 |
| `outside_lane_value` | `45` | 航道外语义编码，须与管理器outside_value一致。大小不是风险半径，修改需同步上下游。 |
| `outside_lane_penalty` | `1.0` | 全局A*航道外额外行程代价。增大：更少离开主航道；减小：更愿选择安全航道外短路线；不能绕过硬危险阈值。 |
| `safety_costmap_topic` | `/local_costmap` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `safety_cost_threshold` | `88` | 航道外物理格禁止阈值，>=此值及未知拒绝。增大：允许更高代价、更贴危险区；减小：更保守且可能无解；与Hybrid岸边阈值一致。 |
| `terminal_crossing_distance` | `100.0` | 起点/终点非主航道连接半径(m)。增大：宽航道/远外目标更容易连通，但可借用更长非主航道；减小：更晚跨入、更可能无解。 |
| `opposite_lane_penalty` | `4.0` | 全局A*左/对向航道额外行程代价。增大：更晚跨入、减少对向行程；减小：更可能较早跨入；建议高于航道外偏好代价。 |
| `center_cost_weight` | `0.08` | 全局A*语义代价倍率。增大：更偏好右航道中心且避免高类别代价；减小：更偏短距离/贴边；与额外区域代价共同生效。 |
| `max_search_iterations` | `200000` | 全局A*最大出队次数。增大：复杂长路线更可能找到、耗时增加；减小：更省算力但易达到上限，无解不自动重试。 |
| `map_settle_time` | `0.5` | 目标/角色变化后等待输入更新的时间(s)，无规划timer。增大：更易合并抖动但启动/纠偏停车更久；减小：响应快但可能抢用旧分类。 |
| `minimum_replan_period` | `0.5` | 两次任务尝试的最短间隔(s)，不是固定搜索周期。增大：限制连续请求算力、响应更慢；减小：响应快、TF缺失时尝试更频繁。 |
| `replan_on_lane_role_change` | `true` | true：0..20与75角色互换触发一次纠偏；false：仅目标或人工服务重规划；梯度变化和重复图不触发。 |

## 跨包一致性检查

- 当前本船最高速度4m/s；小型无人船等效规划半径均为0.5m、安全冗余1m，因此普通中心硬净空为2m。Marker长1m宽1.5m只是显示外形。
- Hybrid在7m软域提前规划、2m硬净空由Hybrid负责；tracking_only=true的DWA只跟踪Path，不使用目标船距离停车。
- AIS式远程监视保持80m/40s不变；行动层24m/16s、紧急层8m/6s。风险圈不是感知截止范围，也不等于软/硬避让域。
- 地图尺寸、原点、分辨率与frame应一致；地图膨胀和独立障碍层不得混淆。
- 主航道、外部、对向代价是偏好，安全硬过滤优先；降低偏好不解除危险栅格阻挡。
