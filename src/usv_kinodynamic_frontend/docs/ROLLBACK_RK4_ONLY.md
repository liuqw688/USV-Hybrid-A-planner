本表针对实际MPC闭环入口。独立预览入口也采用0.1秒候选积分、8秒预算、500米搜索范围及20万节点池；预览地图边界保持原值。

原程序将`integration_step`同时用于RK4上限和输出采样间隔。为了满足“其他不变”，新增独立`output_step=0.02`并仅用于结果输出分段，避免修改RK4上限时连带改变输出节点密度。其他候选搜索、终端连接及结果重建逻辑均恢复快照版本。

0.1秒是最大允许积分步长；传播调用受0.04秒碰撞检查间隔或0.02秒输出间隔限制时，实际积分仍会更细。MPC/本船仿真的共享11参数模型、输入接口、积分设置和更新频率没有改动。

## 实际代码变化

相对于稀疏化之前的源码：

- `kinodynamic_astar.hpp`：RK4上限0.02→0.1，补充独立输出采样间隔0.02。
- `kinodynamic_astar.cpp`：验证输出间隔参数；重建输出按独立间隔采样。
- `tracking_node.cpp`：放宽三个搜索资源上限，公开读取RK4上限参数；其余恢复快照。
- `open_water_node.cpp`、`config/open_water.yaml`：对应调整预览入口的RK4和三个资源上限。
- `open_water_tracking.launch.py`：提供`max_search_time/search_horizon/max_nodes`启动参数，默认8/500/200000。
- `config/engineering_defaults.yaml`：更新说明性的RK4最大步长。

具体差异见`artifacts/usv_rk4_only_20261101/diff_from_previous.diff`。本轮回退前版本归档为同目录`before_rollback.tar.gz`。
