# 11参数辨识模型闭环与逐节点航向显示

日期：2026-10-31。按用户要求，将当前空旷水域测试的前端、MPC预测及本船仿真统一为聊天最开始提供的六状态辨识模型。旧力输入模式保留为显式兼容选项，原河道启动入口仍默认使用原模型。

## 使用

```bash
bash /home/l/1015v2/run_usv_tracking.sh --restart auto_goal:=false
```

在RViz使用 **2D Goal Pose** 拖动设置目标位置和船艏方向。青色线为规划航迹，橙色小箭头为每个发布轨迹节点的船体航向，黄色线为实际里程计航迹，蓝色船体为MPC控制的仿真船。规划起点仍来自实际`/odom`，不提供拖动重置船位的预览操作。

默认巡航纵速参考1.0m/s。工程试验命令范围`v_cmd ∈ [-0.4,1.5] m/s`、`|w_cmd|≤0.7 rad/s`，这些范围未经过实船辨识有效性验证。负速度命令可用于模型中的减速响应。输入命令不等于实际`u/r`。

旧模型对照入口：

```bash
bash /home/l/1015v2/run_usv_tracking.sh --restart auto_goal:=false dynamics_model:=force tracking_speed:=1.5
```

## 统一方程与输入语义

状态顺序为`x,y,psi,u,v,r`，输入为`v_cmd,w_cmd`。共享实现位于`usv_mpc_control/identified_dynamics.hpp`，系数固定为本次用户提供的11个数值：

```text
dx   = u*cos(psi) - v*sin(psi)
dy   = u*sin(psi) + v*cos(psi)
dpsi = r
du   = -0.433264281*u + 0.400421432*v_cmd + 0.032263988
dv   = -0.313324916*v - 0.006741061*r - 0.407958500*w_cmd - 0.000993619
dr   =  0.166118168*v - 0.544509453*r + 0.837536662*w_cmd + 0.000626529
```

三者直接调用同一RK4实现，单步≤0.02秒，保留连续航向和横向/偏航耦合。辨识模式不通过裁剪`u/v/r`改变方程；MPC预测超出状态限值则拒绝该候选，仿真状态直接来自积分。原力输入模式保留原有处理。

辨识模型包含常数偏置，零命令会产生非零响应。停车、等待与命令超时均用包含偏置和耦合项的逆动力学产生减速/保持命令，不把`v_cmd=0,w_cmd=0`视为静止状态，也不冻结仿真位置。欠驱动模型可能保留小量横向漂移。

新模式执行话题为`/cmd_vel`，消息`geometry_msgs/Twist`，`linear.x=v_cmd`、`angular.z=w_cmd`。该模式不发布也不订阅执行用`/cmd_wrench`。原力模式仍使用`/cmd_wrench`的推力/力矩语义。路径、目标、限速配对和里程计接口保持原有约定。

## 修改前后

| 文件/环节 | 修改前 | 修改后 |
|---|---|---|
| `usv_mpc_control/identified_dynamics.hpp` | 无 | 共享11参数系数、完整六状态导数、RK4及逆动力学 |
| 前端`usv_model.hpp` | 前端自己实现辨识方程 | 包装共享模型，系数与MPC/仿真同源 |

| `boat_simulator.cpp` | 只订阅Wrench，传播原力模型 | 新增Twist订阅与辨识RK4传播，命令超时采用辨识逆动力学减速；原模式保留 |
| `tracking_node.cpp` | 闭环只用共享力模型；仅起终点航向箭头 | 默认辨识模式；匹配命令/状态范围及较远终端连接；逐个Path节点绘制橙色航向箭头 |
| 诊断状态样本 | 末两列固定`tau_y,tau_n` | 辨识模式为`v_cmd,w_cmd`，兼容模式仍标记力输入 |
| `open_water_tracking.launch.py` | 默认力输入闭环、1.5m/s参考 | 默认11参数辨识闭环、1.0m/s参考；同一模式/命令边界传给三个节点 |
| RViz配置 | 显示参考线和实际线 | 新命名的航向显示层，橙色箭头与每个Path节点的四元数一致 |
| 构建依赖 | 前端仅运行时依赖MPC包 | MPC导出共享头文件，前端声明编译依赖，无反向依赖 |
| 启动脚本 | 启动既有闭环入口 | 同一条启动命令进入新的默认模式，支持显式旧模式对照 |

旧`underactuated_model.hpp`和Hybrid共享动力学源文件未改动。原力模式参数YAML未改写。本轮没有启动其他船只或进行避让测试。
