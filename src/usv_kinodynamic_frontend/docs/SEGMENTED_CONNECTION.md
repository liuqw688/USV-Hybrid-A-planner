# 数值连接与分段搜索修改记录

**已回退：**用户反馈效果不佳，已撤销分段搜索并恢复原有搜索流程。以下为试验时的历史记录，不代表当前配置。

## 之前

闭环入口调用一次 `KinodynamicSearch::search`。距离目标小于120米时尝试四段常值命令数值连接；接受首条满足终点和碰撞检查的连接。没有对整条结果继续分段搜索。

## 现在

闭环入口调用 `searchSegmented`：首先从当前里程计六状态直接尝试全程数值连接，即使目标超过120米；失败时原Kinodynamic A*搜索仍可继续。初始搜索使用总预算的70%；若没有完整解，用剩余时间按原配置再尝试一次原搜索。

完整初始轨迹按总时间四等分取中间锚点，最终锚点使用原目标。每段由上一段实际六状态终点出发进行局部Kinodynamic A*搜索，局部搜索终端连接范围2.5米、候选时间4/6/8/12/16秒，各段平分当时剩余时间。每个局部结果仍经过原动力学、状态与碰撞检查；首段及各段交界处使用对应下一段命令，时间戳连续。

仅当四段都成功、最终六状态达到原目标容差、总时长不超过初始轨迹1.2倍、平均偏航角速度平方低于初始轨迹时，才接受分段结果；否则保留已通过验证的初始轨迹。偏航角速度平方仅用于候选结果比较，并不是控制命令变化惩罚，也不保证消除所有曲折。若初始搜索和备用搜索都失败，不发布成功轨迹。

预算为共同搜索预算，求解内部按迭代检查，实际墙钟时间可能稍有超出。四段局部搜索有严格目标容差，可能经常无法在剩余预算中全部成功，此时会回退。日志显示成功段数和是否接受结果。局部搜索是在静态地图上的近似搜索，不保证全局最优；MPC跟踪与实际效果还需验证。
