# 控制变化代价修改记录

**已回退：**按用户要求撤销本次试验，闭环终端连接范围恢复为120米，普通搜索和终端连接累计代价恢复为按控制段时间加权的命令幅值惩罚；终端连接数值求解恢复为仅使用终点六状态误差。以下保留试验时的记录，不代表当前生效配置。

闭环前端的终端连接触发距离由120米改为10米。普通搜索控制段仍为0.5/1.0秒。

原控制代价为每段时间乘以0.05倍归一化命令平方和。现在每次控制段切换增加 `0.05 * ((Δv_cmd/1.5)^2 + (Δw_cmd/0.7)^2)`；归一化分母实际取配置的命令上下界，以上为辨识模型默认值。时间代价和地图代价不变。第一段的前一命令由起始状态的动力学逆模型估计，并非接收到的实际上一条命令。

终端连接四段均计入相邻命令变化，包括与进入连接前命令之间的变化；数值求解的残差也包含相同的归一化变化惩罚，终点六状态误差和碰撞检查仍须达标。该惩罚是每次切换的离散代价，不乘以控制段持续时间，并非连续时间命令变化率积分。

搜索节点去重仍按六维船舶状态，未把前一命令纳入离散键，因此此历史相关代价下属于近似搜索，不保证最优。终端连接仍接受第一条满足条件的解；平顺性需要实际验证。
