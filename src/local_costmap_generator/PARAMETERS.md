# 参数作用及调节说明

本说明对应当前源码与配置，不承诺每个参数可在线更新。多数参数仅在构造时读取：编辑YAML后请停止旧实例并重新启动。launch内追加参数可能覆盖YAML；可用 `ros2 param dump /节点名` 核对运行值。

数值“增大/减小”指其他条件不变时的趋势，不是无限调大都有效。布尔值按开/关解释；话题和frame必须与生产者一致。不要同时降低安全半径、冗余及急停距离来追求直线效率。


## config/local_costmap.yaml

当前配置值不是节点内置默认值，其他launch也可能覆盖它。

| 参数 | 当前YAML值 | 作用、关联及调大/调小影响 |
|---|---|---|
| `input_topic` | `/chart_costmap` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `output_topic` | `/local_costmap` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `occupied_threshold` | `90` | 输入格成为硬障碍距离传播种子的门槛。增大：较少格被视为硬障碍；减小：更多格产生膨胀、更保守。 |
| `unknown_is_obstacle` | `true` | 兼容参数：当前活动buildCostmap未读取此开关，true/false均保留未知-1；不能通过改false放开未知水域。 |
| `robot_radius` | `3.0` | 障碍硬高代价(99)扩展半径(m)，不是仅显示船体半径。增大：高代价禁入带更宽；减小：更贴岸；当前3m与规划半径1.5m不同。 |
| `inflation_radius` | `15.0` | 障碍半径外/高代价源的渐变传播范围(m)。增大：更宽梯度、可通行空间/计算受影响；减小：更近才产生代价。 |
| `minimum_cost` | `1` | 膨胀公式远端基准代价。增大：传播范围内远端代价更高；减小：更接近自由区；当前不是全图低值统一清零阈值。 |
| `high_cost_threshold` | `50` | 未达硬障碍但作为高代价源的门槛。增大：高代价种子更少；减小：更多输入格参与第二距离传播。 |
| `decay_factor` | `3.0` | 指数衰减系数。增大：同距离代价下降更快；减小：高代价保持更远；传播总半径仍由inflation_radius控制。 |

## 跨包一致性检查

- 当前本船最高速度4m/s，本船半径1.5m，目标船速度2m/s、半径2m，安全冗余4m。船体Marker外观长1m宽1.5m不等于碰撞半径。
- 默认动态间隔7.5m与当前距离急停8m不是同一参数；追越还可能采用9m。
- 目标船2m/s时，40/24/10s对应距离阈值80/48/20m；只改时间不会自动修改现有YAML距离值。
- 地图尺寸、原点、分辨率与frame应一致；地图膨胀和独立障碍层不得混淆。
- 主航道、外部、对向代价是偏好，安全硬过滤优先；降低偏好不解除危险栅格阻挡。
