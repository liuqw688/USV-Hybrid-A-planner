# 开阔水域 B 样条评价规则

开阔水域启动时 `trajectory_quality_monitor.py` 订阅 `/planning/bspline`，每条新样条输出一条 JSON：终端日志、`/fast_planner/trajectory_quality` 话题、默认 `~/.ros/usv_trajectory_metrics.jsonl` 文件。每次启动生成独立 `run_id`，文件以追加方式保存；可通过启动参数 `trajectory_metrics_file:=...` 指定路径，设为空字符串时不写文件。记录只代表评估时最新地图和最近收到的目标/里程计，不包含实际完整航行效果。

## 固定评价方法（版本 1）

每条样条按其 knots 的有效时间区间取 1001 个等时间样本，按样条解析求导。平面速度小于 0.3 m/s 的样本不计算曲率；曲率 RMS 按弧长加权，记录有效弧长比例。最大值是采样最大值，不是连续极值。

首先检查 `screening` 与 `warnings`：

- `map_unavailable` / `outside_map`：缺地图或轨迹样本位于地图外；未知栅格与地图外按障碍对待。
- `sampled_clearance_below_3m`：采样点到原始占据栅格的保守估计净距低于 3 m。3 m 对应当前规划器膨胀配置；该估计按 EDT 栅格中心距离减去一个格子对角线，不能替代连续碰撞检查或船体扫掠。
- `estimated_v_cmd_out_of_range`、`estimated_w_cmd_out_of_range`：由轨迹导数和现有船模反算命令的采样估计分别超出 [0,2] 或 [-0.3,0.3]；反算还需结合侧滑模型残差，不能等同实船执行器测量。
- `yaw_rate_over_0.3`、`yaw_acc_over_0.1`：采样峰值超过当前规划器角速度或角加速度参考限值。
- `sway_model_residual_rms_over_0.05`：反解后侧滑加速度与船模预测的 RMS 差超过 0.05 m/s²。该 0.05 是工程诊断门限，不是实船认证标准。
- `curvature_unavailable_low_speed`：没有足够非低速样本，不能计算曲率。

有任一标记则 `screening=needs_review`；无标记只表示这些有限样本没有检测到以上问题，不等于安全或动力学可行。

## 工程对比分数

`engineering_score_100` 为固定的辅助对比分数，满分 100，**不覆盖任何安全标记，也不是安全认证**。缺少地图、有效曲率或路径长度为零时分数为 null：

- 路径效率：`25 * min(1, 起终点弦长 / 轨迹长度)`；
- 几何平滑：`30 / (1 + 曲率RMS / 0.1)`，曲率单位 1/m；
- 航向平滑：`25 / (1 + 航向jerkRMS / 0.1)`，jerk 单位 rad/s³；
- 采样净距：`20 * min(1, 净距估计 / 5.0m)`。

其中 0.1 和 5 m 是可复现比较的工程尺度，而非船舶物理极限。建议先排查 `warnings`，再比较得分及原始指标；不同测试地图、起点/速度、目标及轨迹终点/进展不同，不能仅按总分或局部长度判断优劣。曲率与船艏航向分别评价，因为侧滑时它们不相同。

每条还记录目标剩余距离、目标航向误差、样条起点与接收时最近里程计的距离、规划年龄、速度/角加速度峰值、反解命令与侧滑残差。`receive_start_gap_m` 受规划计算和消息时差影响，不是严格同步的衔接误差。完整任务还应单独记录碰撞、到达率、总航程、实际速度/跟踪误差、规划耗时和多次重规划的连续性。

## 重复测试

固定地图及圆障碍位置/半径、起点状态和目标，再逐项改变参数。使用相同 `run_id` 区分一次启动的所有轨迹；对比不同运行时，同时核对目标进展、来源/终点与样条是否代表相同航段。推荐多目标、多障碍布局、多次重复，并报告失败次数及实测跟踪结果；单次分数不足以说明算法普遍更好。
