# 参数作用及调节说明

本说明对应当前源码与配置，不承诺每个参数可在线更新。多数参数仅在构造时读取：编辑YAML后请停止旧实例并重新启动。launch内追加参数可能覆盖YAML；可用 `ros2 param dump /节点名` 核对运行值。

数值“增大/减小”指其他条件不变时的趋势，不是无限调大都有效。布尔值按开/关解释；话题和frame必须与生产者一致。不要同时降低安全半径、冗余及急停距离来追求直线效率。


## config/virtual_boat.yaml

当前配置值不是节点内置默认值，其他launch也可能覆盖它。

| 参数 | 当前YAML值 | 作用、关联及调大/调小影响 |
|---|---|---|
| `vessel_name` | `"Target-Vessel-01"` | 虚拟船身份字符串，用于状态及文字显示；修改不影响航迹或规则。 |
| `vessel_type` | `"VIRTUAL_SIM"` | 虚拟船类型诊断字符串，当前不驱动差异化动力学；修改不改变避让规则。 |
| `length` | `1.0` | 虚拟船显示长度(m)。增大/减小只改变RViz模型；Hybrid半径由target_ship_radii单独设置。 |
| `width` | `1.5` | 虚拟船显示宽度(m)。增大/减小只改变RViz模型；开阔图width则是格子数，见本包说明。 |
| `initial_speed` | `2.0` | 启动实际/目标线速度(m/s)。增大：初始运动更快；减小：更慢；本船受限速和惯性、虚拟船直接匀速积分。 |
| `update_rate` | `20.0` | 虚拟船积分/发布频率(Hz)。增大：数据更密/计算增加；减小：更粗，过低会触发目标2s失联保护。 |
| `initial_x` | `25.0` | 虚拟船初始东向坐标(m)，增大向东、减小向西；相遇类型随布置变化，launch可覆盖YAML。 |
| `initial_y` | `0.0` | 虚拟船初始北向坐标(m)，增大向北、减小向南；与本船统一odom数值坐标。 |
| `initial_yaw` | `3.141592653589793` | 虚拟船初始yaw(rad)，增大逆时针、减小顺时针；改变运动方向与会遇类型。 |
| `command_topic` | `/target_boat/command` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `odom_topic` | `/target_boat/odom` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `status_topic` | `/target_boat/status` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `markers_topic` | `/target_boat/markers` | ROS消息接口名称（列表按目标对应）。修改需同时匹配发布方/订阅方及RViz；名称大小没有调参含义，失配会收不到数据并等待/停车。 |
| `base_frame` | `target_boat/base_link` | 坐标系/TF frame名称。修改须与消息头、TF及接收节点一致；不是数值大小参数，缺失或失配会拒绝输入。 |

## 跨包一致性检查

- 当前本船最高速度4m/s；小型无人船等效规划半径均为0.5m、安全冗余1m，因此普通中心硬净空为2m。Marker长1m宽1.5m只是显示外形。
- Hybrid在7m软域提前规划、2m硬净空由Hybrid负责；tracking_only=true的DWA只跟踪Path，不使用目标船距离停车。
- AIS式远程监视保持80m/40s不变；行动层24m/16s、紧急层8m/6s。风险圈不是感知截止范围，也不等于软/硬避让域。
- 地图尺寸、原点、分辨率与frame应一致；地图膨胀和独立障碍层不得混淆。
- 主航道、外部、对向代价是偏好，安全硬过滤优先；降低偏好不解除危险栅格阻挡。
