# 大航向差、低速掉头规划与测试

近距离追加修复和最新测试见 [近距姿态修复](CLOSE_GOAL_TURN_FIX.md)：新增1.2m/s、3m回退及按艏向差检查必要航程；下面保留普通大角度机制的介绍。

## 原因

原来的欠驱动扩展仅跟踪固定4m/s巡航速度。即便把8m半径参数单独减小，0.45rad/s艏摇率也使常速控制尺度至少约为4/0.45=8.89m，不能凭改半径获得任意急转。空间不足时，搜索容易反复接近目标位置，却无法满足目标艏向，最终耗尽3秒预算。

旧快速连接只适用于起终点都在主航道的缓弯，反向目标/换到另一侧航道时通常用不上。掉头引导还必须区分船体艏向与带侧滑的航迹切线，否则末段可能错过艏向验收。

## 修改与函数联系

正常航行的8m半径、4m/s最高速度和原Hybrid搜索框架保留。仅大航向差启用额外候选：

```text
目标艏向与当前艏向差达到阈值
    → 常速、多半径Dubins空间引导
    → 用真实初始x/y/艏向/u/v/r执行六状态RK4积分
    → 每个子步primitiveIsSafe检查河岸/障碍/动态预测/COLREG
    → 常速失败：目标速度2m/s、控制半径5m再尝试
    → 引导仍失败：在低速模式下执行原Hybrid搜索
    → 最新船位/地图/交通复验、长度和绕圈检查
    → 发布Path和配对限速 → MPC减速跟踪
```

- `setLargeTurnParams`设置功能开关、低速回退速度、半径和航向差阈值。
- `search`先尝试大角度连接，再走原搜索；不瞬间把实测4m/s初始速度重置成2m/s。
- `refineBroadChannelCurve(..., maneuver=true)`用Dubins作引导，而非直接输出几何曲线；尝试不同半径、前视距离和末端航迹切线偏置。始终按原始目标艏向验收，不改用户的目标方向。局部最近点匹配避免跳到掉头曲线的后半段。
- `planningSpeed`/`planningRadius`提供当前路径使用的巡航和转向控制尺度；积分、回溯和时间预测采用同一模式。
- `primitiveIsSafe`支持末段较短的积分时长，以免一个2m基元跨过终点。`extractPath`按父子节点实际累计时间差重建，不把可变时长误当固定时长。
- `heuristic`在低速掉头回退时加入Dubins方向距离，减少只靠近位置、不转好艏向的扩展。仍为加权启发式，不承诺数学意义上的最短路径。
- `publishSpeedLimit`给MPC发布与Path相同时间戳和坐标系的限速。后台失败不会把正在执行的旧路径模式改掉。

正常缓弯的宽弧偏好保留；大航向差降低宽弧软惩罚，允许必要的紧一些的机动。河岸、独立障碍、时间同步动态净空和COLREG硬检查不放宽。掉头可能必须临时借道，但区域软代价和安全约束仍计算。真的无安全解、目标姿态物理不可达或路径绕圈/过长时仍停车，不能保证任何起终点都能航行到达。

## 参数操作

文件：`config/hybrid_a_star_params.yaml`。

| 参数 | 当前值 | 调整含义 |
|---|---:|---|
| `large_turn.enabled` | true | false关闭新增掉头/低速回退，保留原规划模型 |
| `large_turn.heading_threshold` | 1.57rad | 约90°；减小扩大启用范围，增大仅极大角度启用 |
| `large_turn.speed` | 2m/s | 回退路径目标速度；降低可减小艏摇率限制对应的控制尺度，但航行更慢且侧滑比例可能增大 |
| `large_turn.min_radius` | 5m | 仅回退使用；减小允许更紧的控制，建议先保持5m，不建议直接设极小值 |
| `min_turning_radius` | 8m | 正常路径仍使用此值，不需要为掉头把整个项目的正常半径调小 |
| `usv.max_yaw_rate` | 0.45rad/s | 本次不提高执行器/船模能力，不能靠无限增加此值获得不可跟踪的转弯 |

5m是转向控制约束尺度，并非任何初始速度/侧滑状态下地面曲率都严格等于1/5。初始4m/s先由船模逐渐减速，艏摇响应和侧滑仍由原模型决定。

MPC配置位于 `../usv_mpc_control/config/mpc_params.yaml`：`speed_limit_topic: /hybrid_a_star/speed_limit`，消息为 `geometry_msgs/msg/TwistStamped`，`twist.linear.x`表示m/s参考速度上限，其余分量不用；实际速度受惯性和优化控制影响，会逐渐减速，不是直接截断船速。`require_speed_profile: true`要求新的几何路径与对应限速配对。同形路径心跳沿用已匹配限速，不周期性等待。独立接入不发布此消息的旧规划器时才关闭此选项。一键启动应保持true，两端话题名一致。

2m/s回退上限保持到该局部路径结束/被新路径替换；下一条正常路径重新发布正常限速。MPC的弯道和终点减速仍可选取更低的目标速度。

## 操作与测试

重启一键启动节点，重新在RViz选择目标点及目标方向。可执行 `ros2 topic echo /hybrid_a_star/speed_limit`查看当前上限，`ros2 topic echo /hybrid_a_star/planning_status`区分求解和无安全解。

新增 `LargeHeadingTurn`单元测试覆盖左右90°、135°、180°，0和4m/s起步，28m宽静态水域的2m/s/5m回退、初始速度连续性、动态船净空以及无连接硬障碍墙拒绝。原COLREG、平滑、船模等回归测试保留。

真实ROS节点加六状态仿真闭环脚本：`../usv_mpc_control/test/test_large_turn_tracking_ros.py`，可加`--narrow`。默认隔离域178；窄水域测试使用域179。完整加载项目YAML，运行实际Hybrid与MPC节点，不连接真实船或用户正在运行的RViz。具体结果见同包 `LARGE_TURN_TEST_REPORT.md`。这些不是实际河图所有目标姿态的可达性保证。
