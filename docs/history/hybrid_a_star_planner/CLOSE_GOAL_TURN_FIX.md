# 近距离、大艏向差目标的规划修复

## 为什么上一轮仍可能失败

仅降低普通掉头速度和半径不足以解决所有近距离目标：

1. 引导的最大积分步数按直线距离计算。目标虽然仅在前方0.5–5m，满足反向艏向仍可能需要数十米航程，旧预算提前结束。
2. 只按位置靠近就缩短末段积分；起点本来就靠近目标时，在错误艏向下也反复做极短步。
3. 终点绕圈检查只比较位置，可能把“位置很近但还未完成反向艏向”的必要机动拒绝。
4. 长度门槛只按直线距离计算；常速不合格候选先返回节点，再被节点拒绝，下次重复同一结果，低速候选未获机会。
5. 欠驱动船体的艏向不等于航迹切向。短距离几何连接的末端仍在转弯、存在侧滑，直接追逐前视点容易错过端点姿态。

## 当前处理流程

```text
实测当前位置、艏向、u/v/r + 原始目标姿态
  → 判断普通大角度 / 15m内且艏向差≥45°的近距机动
  → 常速4m/s候选 → 普通掉头2m/s、5m候选
  → 近距额外1.2m/s、3m候选
      → 高速时积分减速入弯前缀
      → 多半径Dubins空间引导 + 终点前4/6/8m对准直段候选
      → 近距精细积分；最低速候选使用六状态短时控制采样
  → 每一实际积分子步检查静态障碍、预测船位置及COLREG硬约束
  → 原始目标位置/艏向验收 + 长度/可避免绕圈检查
  → 最新实测状态安全复验 → Path + 配对参考限速 → MPC跟踪
  → 无合格连接时继续原Hybrid搜索；真实无安全解仍撤销路径并停车
```

起点不前移、不按船速/角速度补偿求解耗时。高速减速前缀是真正的候选路径，从原始实测状态开始，包含真实船模响应和沿途安全检查。正常8m转向尺度、4m/s最高速度、普通掉头5m尺度不变；3m仅用于近距低速回退，不是放宽整条航线的正常转弯半径。

## 函数及包间联系

- `setCloseTurnParams`：读取距离、角度阈值及额外低速转向参数。
- `search`：按模式依次尝试连接；每次规划从实测六状态开始，不瞬间修改初始速度。引导失败仍使用原Hybrid A*搜索框架。
- `refineBroadChannelCurve`：普通宽弧和机动共用船模积分；机动预算按引导航程而非短弦长计算，末段缩步只在沿引导到达末段时启用。近距引导最近点局部、单调前进，避免自交曲线跳段。
- `primitiveIsSafe`：积分控制产生的实际子步；对岸线、独立障碍、同步动态净空和规则方向逐步检查。Dubins只用于引导，不直接作为输出船舶轨迹。
- 机动连接端点位置验收收紧到0.4m，艏向仍为0.22rad；避免原0.8m端点误差叠加MPC减速容差后停得过远。原离散Hybrid回退的位置容差仍为1m。
- `extractPath`：按实际父子累计时间重建减速前缀和可变时长运动基元，保证连接连续。
- `pathHasAvoidableGoalLoop`：位置在最多1m范围内且艏向差小于0.22rad、却仍有超过8m剩余航程，才判为可避免终点绕圈。位置近、艏向相反的起点不直接拒绝。
- `pathQualityAcceptable`：长度门槛改为 `ratio × max(直线距离, 转向半径×起终艏向差, 1m) + extra`。角度用归一化后的绝对弧度；这是质量尺度参考，不是物理最短路径证明。引导内部也做验收，让不合格常速结果能继续尝试低速模式。
- `planningSpeed/planningRadius/setActiveManeuver`：搜索、回溯、发布前安全复验采用同一模式。后台失败保留仍在使用的旧路径模式。
- `publishSpeedLimit`：`/hybrid_a_star/speed_limit` 的 `TwistStamped.twist.linear.x` 是参考速度上限；header与Path配对。MPC仍通过推力/力矩逐渐改变船速。

MPC另修正了近距转向的最近点匹配：实测位置只在当前进度前方有限沿程窗口搜索，不再一次扫描1000个点跳到未走过的终点分支。终点停车保持也要求已经走到路径末段，不能仅因初始位置靠近终点就保持停车。优化目标、船模、动态硬安全保护仍保留。

## 参数和操作

`config/hybrid_a_star_params.yaml` 已加入中文注释：

| 参数 | 默认值 | 调整作用 |
|---|---:|---|
| `close_turn.range` | 15m | 增大：更多短程任务允许精细低速连接；减小：更少任务启用 |
| `close_turn.heading_threshold` | 0.7854rad | 约45°；减小扩大启用范围，增大减少额外连接 |
| `close_turn.speed` | 1.2m/s | 减小可能降低转向所需空间，但航行慢、侧滑比例可能增加；增大需更多空间 |
| `close_turn.min_radius` | 3m | 仅近距低速回退；代码下限3m，增大更平缓但更难近处转向 |
| `large_turn.enabled` | true | false同时关闭普通及近距新增机动连接 |
| `event_driven.max_path_length_ratio` / `max_path_extra_distance` | 3 / 40m | 增大允许更长必要绕行；过大也会容忍较差路径，不建议首先调大 |
| `search_time_limit` | 3s | 增大提供更多困难搜索时间，但结果等待更久；本次未延长默认预算 |

`../usv_mpc_control/config/mpc_params.yaml`：`projection_forward_distance: 6.0`（m），并至少覆盖当前2秒航程，向后匹配最多2m。增大更容易捕获较远路径，但自交处更容易跳段；减小更稳定，但严重偏离时重捕获慢。新路径会重置匹配进度。

## 测试及边界

20个近距姿态案例覆盖0、0.5、1、2、5m邻近目标，67.5°、左右90°、135°、180°，以及0和4m/s起步。该组每个案例都检查端点位置<1m、艏向差<0.22rad、路径长度及无可避免终点绕圈；搜索约0.02–0.25s。这里0m指目标位置与起点相同、目标艏向反向，仍需离开起点完成机动。

Hybrid/COLREG共57项、MPC跟踪/坐标变换8项单元测试通过。28m宽水域回退、动态目标3m净空以及不可连通硬障碍墙拒绝测试仍通过。后台无解搜索期间安全旧路径最长刷新间隔约1.002s，取消任务仍发布空路径停车。

### 最终节点闭环结果

起点(0,0)、艏向0、初始u=4m/s，目标艏向均显式设为π；低速到达后继续观察5秒。Path消息也检查末端艏向，避免脚本只测到位置。

| 工况 | 首条路径等待（含调度） | 参考上限 | 最大跟踪偏差 | 最终位置误差 | 规划端点位置 / 艏向误差 |
|---|---:|---:|---:|---:|---:|
| 前方2m、180° | 1.356s | 1.2m/s | 0.453m | 0.374m | 0.292m / 0.207rad |
| 前方0.5m、180° | 1.302s | 1.2m/s | 0.788m | 0.538m | 0.374m / 0.024rad |
| 28m宽水域，目标(-30,10)、180° | 3.705s | 2m/s | 0.845m | 0.624m | 0.832m / 0.151rad |

三项均达到位置<1.05m、最终合速度<0.15m/s的闭环验收，首条路径<5s；窄水域任务仍明显慢于开阔近距连接，不代表全部搜索都能在0.25s内完成。节点日志及JSON指标在 `/tmp/usv_large_turn_*`，清理临时目录后会丢失测试产物。

`test_mpc_readiness_ros.py` 输入/TF/限速配对和空路径制动回归通过，测试等待时间跨过3秒日志节流窗口。此前闭环脚本的Quaternion默认w=1问题已修正为z=1、w=0；旧记录已在 `LARGE_TURN_TEST_REPORT.md`标明实际测试角度，不能当作180°结果。

这些测试不启动RViz，也不接入实际河图或真实船。MPC终点验收仍以位置和稳定停车为主，不等同于最终实船艏向精确控制；两项近距闭环实际停船艏向误差约0.44/0.33rad。近距离反向目标在仅前进的欠驱动模型下，可能必须多弧机动，不能强求所有姿态都是单一C弯。河道空间不足、障碍阻断或碰撞风险不允许时，仍应返回无安全路径，不能通过忽略安全代价强行出轨迹。
