# 终点艏向容差、特殊借道与紧凑低速转向

## 本次行为

1. USV终点艏向容差默认从约12.6°放宽为30°。运动连接、宽弧和格点验收使用统一参数；还会检查输出艏向相对于**原目标方向**的误差，不能通过多次方向偏置累加超出容差。目标位置和碰撞门槛不变。
2. 正常航行仍优先主航道中央/主航道，保持原区域软代价。原目标艏向差超过约40°，或目标位置方向差超过约46°，识别为特殊转向；这类任务不再把主航道边界当作硬墙，必要时可以安全借对向航道或航道外自由水域。河岸、障碍物和COLREG硬检查不放宽。借道是特殊转向的可选项，不等于正常允许长期逆向航行，主航道的判定与任务锁定方式没有修改。
3. 若前方目标的末端要求朝右，而其横向位置不在右方，单一右转C弯可能无法到达；此时允许必要的先左后右机动，不再为了“必须C型”而拒绝所有安全多弧候选。普通后方掉头仍优先单向C弯；C质量同时检查地面曲率和艏向反转。
4. 第一条高速路径若起始直航太长或绕行太长，会继续按顺序降速重试，而不是立刻接受。各档仍从实测位置、艏向、u/v/r积分，没有重置实际航速，也没有外推起点补偿计算耗时。首个合理高速解仍优先，失败或质量差才降速。
5. 特殊C弯先尝试较紧凑的控制幅度；近距离引导连接最多1秒直线减速过渡，随后边转边减速。30m以内特殊机动用短前视/船模控制外推候选，避免远前视切角、漏过终点后又绕回来。最终路径仍由欠驱动模型积分，不是直接拉动几何曲线。

## YAML参数

文件：`config/hybrid_a_star_params.yaml`。角度使用rad，长度使用m。

| 参数 | 默认 | 调小/调大的影响 |
|---|---|---|
| `goal_heading_tolerance` | 0.5235987756（30°） | 小：末端更精确但更难找到路径；大：较易得到短路线，但末端朝向允许偏差增加。代码限定0.05～1.0rad。 |
| `maneuver.max_initial_straight` | 6.0 | 特殊机动高速候选的起始直段质量门槛，实际取max(此值,弦长20%)。小：更积极降速、提前入弯；大：允许更长高速直段。 |
| `maneuver.max_detour_ratio` | 1.7 | 候选长度门槛=ratio×max(弦长,R×艏向差)+10m。小：更偏好紧凑低速机动；大：更容易接受高速宽绕行。 |
| `maneuver.compact_guidance_distance` | 30.0 | 此弦长以内的特殊引导使用短前视和必要的控制采样。大：覆盖更远机动、计算量增加；小：较远机动使用普通宽弧引导，可能不适合小半径。 |
| `speed_sampling.samples` | 10 | 4.0～1.2m/s均匀顺序尝试；多：速度选择更细、工作量增加；少：更快但可能错过合适中间速度。 |
| `speed_sampling.stage_time_limit` | 0.12s | 同一速度的艏向候选共享短阶段预算；最低速保留阶段剩余预算。大：搜索更充分但延迟增加；小：更快进入低速但可能错过高速格点解。共享地图预处理仍计入任务总预算。 |

6m与1.7是继续降速的**质量门槛**，不是安全距离，也不是所有困难机动都能强制满足的硬约束。最低速仍保留原安全/路径质量回退，必要绕行不能简单剪掉。正常8m转向尺度和低速5m/3m尺度、最大转艏率约束仍保留。

## 函数关系

```text
search：根据原目标确定普通/特殊任务
  → 普通任务：主航道优先；特殊任务：允许带代价的安全借道
  → 逐档参考速度（同一档顺序尝试容差内艏向）
  → searchAtSpeed
      → connectMonotoneTurn：短过渡、船模射击C弯
      → refineBroadChannelCurve：宽弧/短前视船模连接，必要时多弧
      → 原Hybrid格点搜索回退
  → 原方向容差复验 → 起始直段/绕行长度质量检查
      → 合理：返回；高速候选过长：下一低速档
  → 节点按最新船位与交通复验 → 路径及参考速度 → 原MPC
```

MPC/DWA及仿真船体模型未修改。MPC已有参考速度订阅，会按规划限速跟踪；这不是把仿真器最大速度整体降低。
