# 历史资料归档

这些文件记录较早版本的设计、参数、对照模型和测试，保留用于追溯已丢失的项目背景。
它们不属于当前运行包，也不会由CMake安装。旧参数和启动命令可能已经退役；当前入口见根目录README与PROJECT_CONTEXT。

- 各包目录：历史修复报告、精简前的说明与参数表。
- hybrid_a_star_planner/report_tools、docs：旧版本对照绘图工具和图。
- free_water_map：仅适用于旧DWA控制链路与旧安全参数的测试配置。
- 完整清理前源码：artifacts/code_cleanup/source_before_cleanup.tar.gz。
