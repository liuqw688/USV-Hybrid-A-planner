# MPC稳定跟踪与Hybrid A*提速

## 本次修改

1. 最终目标的速度允许平稳下降到零；进度参考也使用相同减速包络，不再要求减速中的船以4m/s追赶参考进度。
2. 普通经过点不强制停车，但前方弯道会降速：`v_ref ≈ sqrt(max_lateral_acceleration / 曲率)`。这是一种速度偏好，并受经过点最低速度限制，不是严格横向加速度保证。
3. 中间段的预测参考可以沿末端切线延续，避免5秒预测窗口把局部段末端当成停车墙。新段到达后立即使用新路径。延续仍经过地图、船体及动态避碰检查；最终任务点绝不延续。
4. 控制热启动不再被每次重新构造的种子覆盖；按实际控制周期移动结点。当前与上次实际偏航力矩，以及预测窗口内相邻控制结点，都受变化率约束。紧急制动可绕过此约束，安全优先。
5. 侧滑修正连续变化，不在0.25m/s附近突然跳变。非零低速侧滑仍要准确处理，只有接近真正静止才消退。终点低速航向代价逐步减弱，增加横向误差、速度、侧滑和艏摇权重。
6. 最终目标0.5m附近、船速低于0.1m/s且剩余侧滑漂移可接受时，仅耗散残余运动，不通过反复转艏制造侧滑来修正厘米级误差。中间航点不进入此停车保持分支。稳定停车不要求艏向强制归零。

## 参数调整

配置：`config/mpc_params.yaml`，修改后重启一键launch。

| 参数 | 当前值 | 调大/调小的影响 |
| --- | --- | --- |
| `max_lateral_acceleration` | 0.6m/s² | 调大过弯更快，调小更稳更慢；最低速度仍受下项限制。 |
| `intermediate_goal_speed` | 2m/s | 经过点/弯道参考速度下限；调小允许进一步减速，不是停车命令。 |
| `curvature_preview_distance` | 12m | 调大更早减速，调小更晚。 |
| `max_torque_rate` | 2/秒 | 调大转向更敏捷但反舵更急，调小更稳但避让响应变慢。 |
| `terminal_heading_fade_speed` | 0.35m/s | 调大更早弱化终点纠艏，调小低速纠艏更积极。 |
| `terminal_hold_radius` | 0.5m | 调大接受更宽松的停车误差；调小更精确但可能增加终点修正动作。 |
| `weight.cross_track/course` | 12/12 | 调大更积极贴线/纠正航向；过大可能增加操纵动作。 |
| `weight.sideslip/yaw_rate` | 3/2 | 调大减少侧滑/艏摇，过大可能导致过弯跟踪迟缓。 |
| `weight.torque_slew` | 0.6 | 调大更偏向连续控制，调小更偏向迅速纠偏。 |

最大速度仍是4m/s，没有修改船模系数、最小转弯半径或动态硬安全距离。控制器不是一直保持最高速度，而是按弯道及最终停车需求调速。

## 规划提速与起点接续

Hybrid A*在起终点均为主航道、普通缓弯时，先尝试16组连续宽弧引导。输出仍由六状态欠驱动船模积分得到，所有子步都检查地图、动态船与COLREG约束。成功后跳过离散搜索；失败、大角度掉头、跨航道目标等情况保留原搜索。没有用船速/角速度外推来补偿耗时。

二维引导场把每个栅格的静态安全/代价求一次，避免八邻域重复进行多层海图查询。异步搜索完成后每50ms检查一次结果，不再额外等下一次1Hz监测回调。

迟到结果根据实测位置裁掉已航行的前缀。最近接续点须满足`result_join_distance: 1.5m`、`result_join_heading: 0.35rad`，且按最新地图及交通重新安全验证；否则拒绝并重搜。不会伪造一条从当前船位硬拼到旧曲线的连线。复杂场景仍可能耗时，不能保证所有目标都有可行解。

## 测试与边界

本次相关三个包共64项回归通过，包括快速连接的独立障碍/动态船安全检查、迟到路径裁剪、侧滑连续性和终点速度参考。

合成河道缓弯同一输入的一次对照：完整搜索约427ms，快速船模连接约3.6ms。该数字不是实际河图全部任务的性能保证；失败回退仍受3秒单次搜索预算限制。

真实ROS MPC节点 + 同系数六状态RK4仿真闭环（直线18m，初始横向偏差1m、艏向偏差0.15rad、纵速2m/s，运行28秒）：

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| 最终位置误差 | 0.334m | 0.134～0.283m |
| 最终横向误差 | 0.333m | 0.046～0.057m |
| 终点段明显反向力矩切换 | 13次 | 2～3次 |
| 终点段相邻输出最大力矩变化 | 5.00 | 0.20 |
| 预测尾端相邻帧最大横向变化 | 0.577m | 0.085～0.111m |

修改后数值列出两次复测的范围；ROS调度与实时积分步长会引入运行差异。最终版本通过了停车误差<0.5m、预测尾端跳变<0.25m、明显反舵不超过5次的回归门槛。

20m半径弯道经过点测试按8m规则交接下一段：末次速度2.88m/s，横向误差0.266m，经过点没有停车，末段没有明显反向力矩切换。

独立ROS路径保鲜回归通过，持续无解重试期间有效旧路径最大间隔0.813秒，任务撤销后发空路径停车。没有做实际河图全程RViz驾驶测试，也没有做实船试验；上述结论只覆盖记录的回归场景。
